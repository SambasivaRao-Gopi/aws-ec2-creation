🚀 Terraform AWS EC2 Deployment

📘 Project Description

This project demonstrates how to provision an AWS EC2 instance using Terraform, following Infrastructure as Code (IaC) best practices. It includes setting up a custom security group to allow SSH (port 22) and HTTP (port 80) access, and deploying the instance into the default VPC.

🧰 Tech Stack

🛠️ Terraform v1.x

☁️ AWS EC2

🔐 AWS Security Groups

💻 Infrastructure as Code (IaC)
